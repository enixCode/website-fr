Comment tu peux aider

Signaler des problèmes

Si tu remarques des bugs, des erreurs ou des incohérences dans le code ou la documentation du projet Go, fais-le-nous savoir en soumettant un ticket sur notre suivi des problèmes. (Bien sûr, vérifie qu'il ne s'agit pas d'un problème déjà existant avant d'en créer un nouveau.)

Nous nous faisons un point d'honneur d'être rigoureux : aucun problème n'est trop insignifiant.

Les problèmes liés à la sécurité doivent être signalés à security@golang.org.
Consulte la politique de sécurité pour plus de détails.

Les problèmes liés à la communauté doivent être signalés à conduct@golang.org. Consulte le Code de conduite pour plus de détails.

Contribuer du code et de la documentation

Go est un projet open source et nous accueillons les contributions de la communauté.

Pour commencer, lis ces directives de contribution pour obtenir des informations sur la conception, les tests et notre processus de revue de code.

Consulte le suivi pour trouver des problèmes ouverts qui t'intéressent. Ceux étiquetés help wanted ont particulièrement besoin d'aide extérieure.

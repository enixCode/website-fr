Introduction

Ce document liste les plugins d'éditeurs et IDE couramment utilisés de l'écosystème Go qui rendent le développement Go plus productif et fluide. Une liste complète des supports d'éditeurs et IDE pour le développement Go est disponible sur le wiki.

Options

L'écosystème Go propose une variété de plugins d'éditeurs et d'IDE pour améliorer ton expérience quotidienne d'édition, de navigation, de test et de débogage.

  • Visual Studio Code : l'extension Go fournit un support pour le langage de programmation Go
  • GoLand : GoLand est distribué soit comme un IDE autonome, soit comme un plugin pour IntelliJ IDEA Ultimate
  • vim : le plugin vim-go fournit un support pour le langage de programmation Go

Note que ce ne sont là que quelques solutions parmi les meilleures. Une liste plus complète maintenue par la communauté des IDE et plugins d'éditeurs de texte est disponible sur le Wiki.

Installation de Go

Sélectionne l'onglet correspondant au système d'exploitation de ton ordinateur ci-dessous, puis suis les instructions d'installation.

  1. Supprime toute installation Go précédente en supprimant le dossier /usr/local/go (s'il existe), puis extrais l'archive que tu viens de télécharger dans /usr/local, ce qui crée un nouvel arbre Go dans /usr/local/go : 
          $ rm -rf /usr/local/go && tar -C /usr/local -xzf go1.14.3.linux-amd64.tar.gz

    (Tu devras peut-être exécuter chaque commande séparément avec les permissions nécessaires, en tant que root ou via sudo.)

    N'extrais pas l'archive dans un arbre /usr/local/go existant. Cette opération est connue pour produire des installations Go défectueuses.

  2. Ajoute /usr/local/go/bin à la variable d'environnement PATH.

    Tu peux le faire en ajoutant la ligne suivante à ton fichier $HOME/.profile ou /etc/profile (pour une installation à l'échelle du système) : 

              export PATH=$PATH:/usr/local/go/bin

    Note : les modifications apportées à un fichier de profil peuvent ne pas prendre effet avant la prochaine connexion à ton ordinateur. Pour appliquer les modifications immédiatement, exécute directement les commandes shell ou charge-les depuis le profil avec une commande telle que source $HOME/.profile.

  3. Vérifie que Go est installé en ouvrant une invite de commande et en tapant la commande suivante : 
              $ go version
  4. Confirme que la commande affiche la version de Go installée.
  1. Ouvre le fichier package que tu as téléchargé et suis les instructions pour installer Go.

    Le package installe la distribution Go dans /usr/local/go. Il devrait ajouter le répertoire /usr/local/go/bin à ta variable d'environnement PATH. Tu devras peut-être redémarrer les sessions Terminal ouvertes pour que le changement prenne effet.

  2. Vérifie que Go est installé en ouvrant une invite de commande et en tapant la commande suivante : 
              $ go version
  3. Confirme que la commande affiche la version de Go installée.
  1. Ouvre le fichier MSI que tu as téléchargé et suis les instructions pour installer Go.

    Par défaut, l'installateur installera Go dans Program Files ou Program Files (x86). Tu peux changer l'emplacement si nécessaire. Après l'installation, tu devras fermer et rouvrir toutes les invites de commande ouvertes pour que les modifications de l'environnement effectuées par l'installateur soient prises en compte.

  2. Vérifie que Go est installé.
    1. Sous Windows, clique sur le menu Démarrer.
    2. Dans la zone de recherche du menu, tape cmd, puis appuie sur la touche Entrée.
    3. Dans la fenêtre d'invite de commande qui s'affiche, tape la commande suivante : 
                    $ go version
    4. Confirme que la commande affiche la version de Go installée.

Cette page décrit comment installer plusieurs versions de Go sur la même machine, ainsi que comment désinstaller Go.

Pour d'autres contenus sur l'installation, tu pourrais être intéressé par :

  • Télécharger et installer -- La méthode la plus simple pour être opérationnel.
  • Installer Go depuis les sources -- Comment récupérer les sources, les compiler sur ta machine et les exécuter.

Installer plusieurs versions de Go

Tu peux installer plusieurs versions de Go sur la même machine. Par exemple, tu pourrais vouloir tester ton code sur plusieurs versions de Go. Pour la liste des versions installables de cette façon, consulte la page de téléchargement.

Note : pour utiliser la méthode décrite ici, tu devras avoir git installé.

Pour installer des versions supplémentaires de Go, exécute la commande go install en spécifiant l'emplacement de téléchargement de la version à installer. L'exemple suivant illustre cela avec la version 1.10.7 : 

$ go install golang.org/dl/go1.10.7@latest
$ go1.10.7 download

Pour exécuter des commandes go avec la version nouvellement téléchargée, ajoute le numéro de version à la commande go, comme suit : 

$ go1.10.7 version
go version go1.10.7 linux/amd64

Lorsque tu as plusieurs versions installées, tu peux découvrir où chacune est installée en consultant la valeur GOROOT de la version. Par exemple, exécute une commande telle que : 

$ go1.10.7 env GOROOT

Pour désinstaller une version téléchargée, supprime simplement le répertoire indiqué par sa variable d'environnement GOROOT ainsi que le binaire goX.Y.Z.

Désinstaller Go

Tu peux supprimer Go de ton système en suivant les étapes décrites dans cette page.

Supprimer la configuration et les données utilisateur

Go stocke la configuration utilisateur dans le répertoire go du répertoire de configuration utilisateur, tel que renvoyé par os.UserConfigDir. On peut aussi le trouver comme le répertoire contenant le fichier de configuration renvoyé par go env GOENV.

Go stocke les artefacts de compilation intermédiaires dans le répertoire renvoyé par go env GOCACHE. Ils peuvent être supprimés avec go clean -cache.

Go stocke les dépendances téléchargées dans le répertoire renvoyé par go env GOMODCACHE. Elles peuvent être supprimées avec go clean -modcache.

Linux / macOS / FreeBSD

  1. Supprime le répertoire go.

    Il s'agit généralement de /usr/local/go.

  2. Retire le répertoire bin de Go de ta variable d'environnement PATH.

    Sous Linux et FreeBSD, édite /etc/profile ou $HOME/.profile. Si tu as installé Go avec le package macOS, supprime le fichier /etc/paths.d/go.

Windows

La façon la plus simple de supprimer Go est via Ajout/Suppression de programmes dans le panneau de configuration Windows :

  1. Dans le Panneau de configuration, double-clique sur Ajout/Suppression de programmes.
  2. Dans Ajout/Suppression de programmes, sélectionne Go Programming Language, clique sur Désinstaller, puis suis les instructions.

Pour supprimer Go avec des outils, tu peux aussi utiliser la ligne de commande :

  • Désinstalle via la ligne de commande en exécutant la commande suivante : 
    msiexec /x go{{version}}.windows-{{cpu-arch}}.msi /q

    Note : utiliser ce processus de désinstallation sous Windows supprimera automatiquement les variables d'environnement Windows créées lors de l'installation d'origine.
